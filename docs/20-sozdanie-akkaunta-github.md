# 20. Как создать аккаунт на GitHub

Инструкция для Веры. Займёт около 5 минут. Аккаунт бесплатный.

Сайт на английском, поэтому ниже нужные слова и кнопки написаны так, как они выглядят на экране.

## Что понадобится

- Почта, к которой у вас есть доступ прямо сейчас: на неё придёт код подтверждения.
- Компьютер или телефон с браузером.

## Шаги

1. Откройте [github.com/signup](https://github.com/signup).

2. **Email** — введите свою почту.

3. **Password** — придумайте пароль. Требования: не меньше 15 символов, либо не меньше 8 символов, но тогда с цифрой и строчной латинской буквой. Пароль сразу запишите в надёжное место.

4. **Username** — имя пользователя, его будут видеть другие. Только латинские буквы, цифры и дефис, например `vera-lukinova`. Если имя занято, GitHub предложит варианты.

5. **Your Country/Region** — выберите страну.

6. **Email preferences** — галочку про рассылку новостей GitHub можно не ставить.

7. Нажмите **Continue** или **Create account**.

8. **Проверка, что вы не робот.** GitHub покажет простую головоломку (например, выбрать картинку). Решите её и нажмите **Submit**.

9. **Код из письма.** На почту придёт письмо от GitHub с кодом из 8 цифр. Введите его на сайте. Если письма нет пару минут, проверьте папку «Спам».

10. **Вопросы о себе** (сколько человек в команде, чем занимаетесь) — можно пропустить кнопкой **Skip personalization** или ответить как угодно.

11. **Выбор тарифа** — выберите бесплатный: **Free** или **Continue for free**. Платить ничего не нужно.

Готово: вы на главной странице GitHub.

## Последний шаг — напишите Льву

Пришлите Льву в Telegram своё **имя пользователя** (Username из шага 4). Без него он не сможет открыть вам доступ к документам проекта.

Дальше от GitHub придёт письмо с приглашением в проект. Что с ним делать — в отдельной инструкции «Как смотреть документы проекта на GitHub».

## Если что-то пошло не так

- **Забыли пароль:** на странице входа [github.com/login](https://github.com/login) нажмите **Forgot password?**, ссылка для сброса придёт на почту.
- **Не приходит код:** проверьте «Спам», затем нажмите **Resend the code**.
- **GitHub просит включить двухфакторную защиту (2FA):** это дополнительная защита входа через приложение-генератор кодов или SMS. Если такое сообщение появится, напишите Льву — он поможет настроить.
