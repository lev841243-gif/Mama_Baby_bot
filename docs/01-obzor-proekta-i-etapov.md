## Чего не достигли

- **Бэкапа нет.** Бакет S3 Beget не создан. Перед выкладкой на сервере есть только `pg_dump` на тот же диск.
- **Не настроено на сервере:** алерты (`ALERT_CHAT_ID`), мониторинг (GlitchTip, Uptime Kuma), секреты GitHub Actions, бот — админ канала (`CHANNEL_ID`).
- **Проверки на телефонах:** чек-лист iPhone и Android (тема, шрифт, аудио, LCP на 4G), лента в свой слот, календарь. Белый экран на iPhone после деплоя: доработки и диагностика выложены, не перепроверено.
- **Контента нет:** на сервере 0 материалов. Без них лента молчит, поиск по смыслу пуст, тест «25 из 30» не на чем прогнать.
- **Этап 3 не закончен:**
    - версия согласия 01 с п. 8 о голосе для поиска (шаг 1);
    - голосовой поиск (шаг 5, нужен сервис речи);
    - помощник автора (шаг 6, нужен выбор модели);
    - счётчик расходов и режимов поиска (шаг 7);
    - приёмка 29–30 (шаг 8).
- **Юрист не привлечён.** Без экспертизы нельзя начинать бета-тест с мамами (ТЗ 12).
- **Бета-тест не проводился** (ТЗ 14).
