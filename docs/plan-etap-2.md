## Шаг 3. Лента: отправка ◐

Сделано 28.10.2026: очередь `feed` в worker, проход раз в 15 минут (`runFeedTick` в `shared/feed.ts`). Решение по времени мамы (`feedDecision`): только в её слот, тихие часы 22–8 сильнее всего, дни отправки — N раз в неделю равномерно с понедельника (2 — пн и чт, **[заглушка Р5]**), не чаще раза в день. Материал: опубликован, «участвует в ленте», возраст включает возраст малыша в полных месяцах (Л4), бесплатный или есть подписка в момент отправки, ещё не отправлялся, по «порядку». Запись «отправлено» и захват дня — в транзакции до отправки: сбой Telegram пропускает анонс, но не дублирует его. 18 месяцев — прощание один раз; пауза — предупреждение накануне конца; младше 3 — ждём; заблокировала бот — `bot_blocked`. Анонс: картинка по подписанной ссылке (подпись ссылок перенесена в `shared/media-sign.ts`), название, анонс, «Материалы автора. Не заменяет консультацию врача», кнопка «Открыть в приложении». В «Сводке» — материалы ленты по каждому месяцу 3–17. Сбой прохода или отправки — алерт. Тесты: решения по времени (пояса, дни, пауза, 3 и 18 месяцев, тихие часы) и проход на Postgres в транзакции с откатом (возраст, закрытое без подписки, без повторов после сбоя, прощание). **Осталось:** проверить на сервере с настоящим ботом (локально worker не запускаем — бот работает на сервере).

Цель: анонсы приходят по возрасту, вовремя, без повторов и только доступные маме.

- Очередь `feed` в BullMQ: планировщик раз в 15 минут выбирает мам, у которых сейчас их слот по их поясу, нет паузы, бот не заблокирован, наступил день отправки по частоте (`feedPerWeek` из админки, по умолчанию 2 — **[заглушка Р5]**: фиксированные дни недели, например пн и чт).
- Подбор материала (ТЗ 7): опубликован, «участвует в ленте», возраст материала включает текущий возраст ребёнка в полных месяцах (ТЗ 5; уточнение — вопрос Л4), доступен маме (бесплатный или в её подписке — проверка на сервере в момент отправки, приёмка 16), не отправлялся (`feed_sent`), по полю «порядок». Неотправленные материалы прошлого возраста не досылаются; материалы закончились — лента молчит.
- Без повторов при перезапуске: запись в `feed_sent` в транзакции **до** отправки (уникальный индекс) — при сбое лучше пропустить анонс, чем прислать дважды (приёмка 26). Перед отправкой — повторная проверка согласия на ленту и основного согласия (отзыв посреди очереди не даёт сообщения, приёмка 3).
- Анонс: картинка (подписанная ссылка `card`), название, 2–3 строки анонса, кнопка «Открыть в приложении» (`startapp=m<ID>`, ТЗ 8.8), подпись «Материалы автора. Не заменяет консультацию врача».
- Тихие часы 22:00–8:00 по времени мамы — жёсткий запрет в коде поверх слотов (приёмка 28).
- Пауза: за сутки до конца — предупреждение «Лента возобновится завтра», затем лента сама продолжает (ТЗ 7, приёмка 28).
- 18 месяцев: прощальное сообщение автора один раз, лента выключается, доступ к материалам, закладкам и календарю остаётся (ТЗ 5, приёмка 27). 3 месяца — первая отправка сама.
- Бот заблокирован (403) → `bot_blocked`, отправка прекращается; разблокировал и написал — снова в ленте (ТЗ 13).
- Порции в пределах лимитов Telegram (transformer-throttler, auto-retry), алерт при ошибках рассылки (шаг 11 этапа 1).
- Админка: тексты прощания и предупреждения о паузе; в «Сводке» — сколько материалов ленты осталось по каждому месяцу возраста (агрегат по контенту, без мам), подписанные по возрастам (уже есть), отписки.
- Тесты: подбор по возрасту и доступу, без повторов при двух параллельных запусках, тихие часы на поясах, пауза, 18 месяцев, блокировка.

## Шаг 4. Голос в боте: распознавание ☐

Цель: голосовое до 60 с распознаётся в РФ за ≤ 10 с, аудио и текст нигде не остаются.

- **[заглушка Р4]** провайдер `transcribe` в едином интерфейсе ИИ (очередь `ai`, ответ — Zod): SpeechKit или SaluteSpeech после сравнения (цена, условия «не хранить и не обучать», лимиты синхронного режима для 60 с); без ключей — фейковый провайдер с фиксированным текстом для тестов. Хранение на стороне сервиса отключено (ТЗ 10.2, 3.6, 3.7).
- Голосовое: проверка длины (> 60 с — текст автора «Пожалуйста, до минуты»), скачивание из Telegram в память, без записи на диск, в S3, Redis и логи; буфер отбрасывается сразу после ответа сервиса.
- Распознанный текст → «красные слова» **до** любого действия; при срабатывании — экстренный текст с 103 и 112, ничего не записывается (ТЗ 10.3, приёмка 25).
- Иначе бот показывает текст (ТЗ 10.2) и кнопки: «Записать в календарь», «Найти материалы» (только если решено, вопрос Л2), «Исправить». Текст в памяти процесса не хранится: сразу извлекается структура для календаря (шаг 5), а для поиска — только ID найденных материалов.
- Кто может слать голос: только с согласием на календарь (или с новой версией основного согласия, если голос для поиска — Л2). Без согласия — предложение включить календарь; аудио не отправляется в сервис.
- Логи: только хеш ID, длительность и время распознавания; ни текста, ни file_id. Тест «в логах нет текста» (приёмка 22).
- **[заглушка Р3]** микрофон в мини-приложении не делаем; по желанию — прототип записи на iPhone и Android в Telegram, решение по итогам.

ТЗ 6.4, 10.2, 10.3, 10.6, 10.7, 11.4, 13 (≤ 10 с); приёмка 22, 25.

**Готово, когда:** голосовое на 50 с распознаётся за ≤ 10 с на сервере, текст показан маме, «красное слово» голосом даёт экстренный текст, в базе, Redis и логах нет ни аудио, ни текста.

## Шаг 5. Календарь: запись в боте ☐

Цель: «Записать навык» → подтверждение → запись, без «Верно» ничего не сохраняется.

- Меню «Записать навык» (ТЗ 6.2): без согласия на календарь — включение (07, раздел 6) → согласие 04 → месяц и год рождения, если нет (ТЗ 6.3).
- Извлечение из распознанного текста трёх значений (ТЗ 10.4): дата («сегодня», «вчера», «15 ноября», «в прошлую пятницу»; не в будущем и не раньше месяца рождения), навык из справочника, статус «старт навыка» / «навык сформирован». Предложение: сначала свой разбор по правилам (стеммер, синонимы навыков, слова статуса — данные мамы не уходят во второй сервис), провайдер `extract` (YandexGPT / GigaChat, **[заглушка Р4]**, Zod) — только если правила не справились. ИИ возвращает только структуру (ТЗ 10.7).
- Синонимы навыков: новое поле «Как говорят мамы» в коллекции «Навыки» («пополз», «ползает» → ползание), стартовый список — на утверждение Вере.
- Не распознано — выбор кнопками: навык (справочник), статус, дата (сегодня / вчера / другой день — календарь кнопками).
- Подтверждение — шаблонный текст автора «Записала: 15.11 — ползание — старт навыка» и «Верно» / «Исправить» / «Отмена» (07, раздел 6). «Верно» — запись; «Исправить» — по полям кнопками; «Отмена» и таймаут — ничего (приёмка 21).

- Тесты разбора: даты, формы навыков, статусы; без «Верно» в базе пусто; «красное слово» в «Исправить» текстом.
