# Тексты этапа 2 для автора

28.10.2026. Новые тексты бота и приложения для ленты и календаря навыков (ТЗ 6.8). Все они правятся в админке: «Тексты бота и приложения» → вкладки «Лента» и «Календарь навыков». Пустое поле — значит текст по умолчанию из таблицы. Слова в фигурных скобках ({times}, {date} …) — подстановки, их не трогать.

Тексты этапа 1 — [teksty-dlya-avtora.md](teksty-dlya-avtora.md). Фразы навыков правятся в «Навыки» → «Как говорят мамы» (по одной в строке).
