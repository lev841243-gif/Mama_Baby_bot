# 21. Как смотреть документы проекта на GitHub

Инструкция для Веры. Займёт 5–10 минут один раз.

GitHub — сайт, где лежат все документы и код проекта «Дневник спокойного материнства». Документы открываются в браузере как обычные страницы, ничего устанавливать не нужно. Сайт на английском, поэтому ниже нужные кнопки названы так, как они написаны на экране.

## 1. Создайте аккаунт (один раз)

1. Откройте [github.com/signup](https://github.com/signup).
2. Введите почту, придумайте пароль и имя пользователя латиницей (например, `vera-lukinova`).
3. Подтвердите почту кодом из письма от GitHub.
4. **Пришлите Льву своё имя пользователя** — без него он не сможет дать доступ.

## 2. Примите приглашение

Проект закрытый, его видят только приглашённые. Когда Лев вас добавит:

1. На почту придёт письмо от GitHub со словами **invited you to collaborate on lev841243-gif/Mama_Baby_bot**.
2. Нажмите в письме **View invitation**, затем **Accept invitation**.

Если письмо не пришло, откройте ссылку [github.com/lev841243-gif/Mama_Baby_bot/invitations](https://github.com/lev841243-gif/Mama_Baby_bot/invitations), войдя в свой аккаунт. Приглашение действует 7 дней — если не успели, попросите Льва прислать заново.

## 3. Откройте документ по ссылке

Лев присылает ссылки такого вида:
`https://github.com/lev841243-gif/Mama_Baby_bot/blob/main/…`

Просто откройте её. Если сайт просит войти — нажмите **Sign in** и войдите в свой аккаунт.

**Видите страницу «404 — Page not found»?** Это значит, что вы не вошли в аккаунт или ещё не приняли приглашение. Проект не пропал: войдите и откройте ссылку снова.

## 4. Как читать документ

- Документ показывается оформленным: заголовки, таблицы, списки и схемы.
- **Оглавление:** в правом верхнем углу документа есть кнопка со значком списка (☰). Она открывает перечень разделов, по нему можно сразу перейти к нужному.
- В начале ТЗ есть «Содержание»: его пункты кликаются и ведут к разделам. Номера в тексте вроде «(8.9)» — это номер раздела, его можно найти через оглавление или поиск.
- **Поиск по странице:** Ctrl+F на компьютере, на телефоне — «Найти на странице» в меню браузера.

## 5. С телефона

Всё работает в обычном мобильном браузере. Широкие таблицы листаются пальцем вбок. Можно также поставить приложение **GitHub** (App Store, Google Play), войти в него и открывать ссылки через него.

## 6. Скачать или распечатать

- Открыть документ → кнопка **Download raw file** (значок стрелки вниз над текстом) — скачается файл.
- Для печати удобнее PDF: попросите Льва, он пришлёт.

## 7. Как передать замечания

Удобнее всего написать Льву в Telegram и указать раздел: «ТЗ 8.9: хочу, чтобы…» или «Вопрос В4: закрываем раздел 9–12 месяцев». В самом проекте ничего менять не нужно.

## Важно

- Вам видны все файлы проекта, включая программный код. Смотреть нужно только документы из таблицы выше, остальное можно не открывать.
- **Ничего не редактируйте и не удаляйте.** Если увидите кнопки со значком карандаша, **Commit changes** или **Delete** — не нажимайте: изменения сразу попадут в проект. Если что-то случайно поменялось, напишите Льву — всё можно вернуть.
