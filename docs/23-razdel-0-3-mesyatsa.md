# 23. Раздел «0–3 месяца»

Дата: 01.11.2026.

По команде Льва добавлен возрастной раздел «0–3 месяца» перед «3–6 месяцев». Возрастной охват приложения теперь 0–18 месяцев. Это дополнение к исходному ТЗ; исторический текст ТЗ не изменён.

## Поведение

- Раздел охватывает полные месяцы 0, 1 и 2. В три месяца ребёнок переходит в «3–6 месяцев».
- Общий список диапазонов используется в приложении, API, подборе материалов и обезличенной сводке. Поддержана ссылка с параметром `s0-3`.
- При выключенном скрытии небольших разделов новый раздел виден даже без опубликованных материалов. Внутри показывается существующее сообщение о пустой вкладке. Видимость остальных разделов не изменена.
- Если скрытие небольших разделов включено, для нового раздела действует тот же порог наполнения, что и для остальных.
- Для детей младше трёх месяцев больше не показывается предупреждение о том, что основные материалы начинаются с трёх месяцев.
- Обновлены описания возраста по умолчанию и текст на стартовой веб-странице.

Админка уже разрешает нижнюю границу возраста 0: для материала новому разделу можно указать «от 0 до 3». Верхняя граница не включается. Миграция базы не требуется. Возраст и статус существующих статей не изменены; материалы без явно указанного возраста остаются черновиками по прежнему решению Льва.

Тексты, сохранённые автором в настройках CMS, имеют приоритет над значениями по умолчанию. При выпуске следует проверить их возрастные формулировки и описание профиля бота; изменение исходников само по себе не перезаписывает авторские настройки. Старый ключ `ageTooYoung` сохранён для совместимости настроек, но для допустимого возраста 0–2 месяца не используется.

## Проверка

- `corepack pnpm typecheck` — успешно во всех пакетах.
- `corepack pnpm test` — успешно; интеграционные тесты, требующие отдельной тестовой базы, пропущены без `TEST_DATABASE_URL`.
- Добавлены проверки границ возраста, пересечения материалов с новым диапазоном, видимости пустого раздела и порога наполнения.
